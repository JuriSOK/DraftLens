# DraftLens

DraftLens is a data-driven NBA Draft decision-support tool for scouting departments, analytics teams, and front-office decision makers. It evaluates NCAA draft prospects using objective pre-draft information and presents two distinct rankings: a General Draft Board of overall prospect quality, and a Team Need ranking that surfaces the players who best match a specific scouting need. Every score it produces is meant to be explainable and traceable back to the factual statistics behind it — DraftLens is decision support, not career prediction.

Built for the **AQX Sports Analytics Data Bowl 3.0**.

## Status: Product Definition / Pre-development

**Application implementation has not started.** There is no application code, no chosen technology stack, and no selected dataset in this repository. The current phase is product definition only.
